# Report requirements (user, 2026-09-28)

The current report is badly written and badly presented. Required:

## Structure
- A clear format, with numbered sections and a TABLE OF CONTENTS at the start.
- Better structure and more colour for readability: coloured section headers, cards and status colours.

## 1. Overview (first, to the point)
- The verdict: is our game optimised, on par with the others, or slightly / relatively / very different?
- The KEY points we can optimise, as a short prioritised list.

## 2. Patterns
- List the patterns and partial patterns found in the competitors.
- For each one, show a check mark if our game fits the pattern, or a clear "different" marker if it doesn't, with the reason.
- Order is a pattern too: the sequence of screen types, e.g. what comes first, second, third.

## 3. Position table (not image lists)
- Do NOT just list images.
- ONE row per store position:
  - row 1 = every game's 1st image, row 2 = every game's 2nd image, and so on;
  - each row begins with OUR image at that position, followed by each competitor's image at that position.
- Each cell carries its label (screen type, headline) and its (i).
- Images in the report can be folded (a global toggle plus per-section folding).

## Semantics
- A title image IS usually a screenshot: the in-game title screen shown when the game opens. Treat it as an in-game screen (title screen), not as pure marketing art, unless it clearly is standalone promotional art.

## Then
- Recommendations: the recommended order, with a full screenshot spec plus a full marketing-layer spec per position.
