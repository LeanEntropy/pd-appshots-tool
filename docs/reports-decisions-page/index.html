What the plan does

  • A project can hold many reports: Pilot, Full check, One country, and Compare countries.
  • One "New report" builder shows exactly what each report needs — free, cheap or full-price images — and the cost, before anything runs; a report that needs no new AI builds instantly.
  • Country reports are the expansion step: the same builder, opened prefilled after the Full check asks "how do you want to expand?"
  • Compare countries shows, per country, our screenshots against competitors', how each game's pictures and text change across countries, and recommendations per country.
  • Saved reports are immutable versions; a "Newer data" badge appears when the underlying data has changed, and reports can be archived.
  • The Report tab lists every report with Export PDF, Regenerate, Rename, Archive and Delete.
  • PDF export drives the installed Chrome or Edge browser, for high-quality PDFs of the wide position tables.
  • A free "Suggested next research" panel, computed from what's already on disk, points to the best next thing to check — nothing runs without approval.
Also added since the last review:
  • A terminology comparison, per country — how competitors' wording differs from ours, side by side.
  • Every report now ends with a short set of suggested A/B tests, written in a CMO's voice.
  • Reports now show, per country, the store category, tags and keywords derived from each game's listing.

Your decisions

Nine open decisions, D1–D9. Each has a recommended default, highlighted below — approve it, ask for a change, or flag a question, with an optional note.

D1

Allow country and compare-countries reports only after the Full check has recommendations?

RecommendedYes.

AlternativesAllow them any time — their recommendations would then have no core base to build on.

WhyFollows the expanding-circle rule: country advice is built from the Full check's own recommendations, so it needs to exist first.

Correction: Rogue Legend has only PILOT recommendations so far. The Full check (39 images left, about $7–13) would have to run first.

D2

If a competitor's English image isn't analysed yet, analyse it once so its other countries only need the cheap text comparison?

RecommendedYes.

AlternativesSkip the English anchor and run a full analysis for every country instead.

WhyOne English analysis plus several cheap text comparisons is reliably cheaper than a full analysis per country, and it's shown in the list with the reason.

D3

Can Pilot and Full check reports be archived but not deleted?

RecommendedYes.

AlternativesAllow deleting them too.

WhyThey carry the analysis freshness pointers that other reports and the "Newer data" badge depend on.

D4

Should the PDF default to A4 landscape?

RecommendedYes.

AlternativesA4 portrait · Letter.

WhyThe position tables are wide, and landscape keeps them readable without shrinking the text.

D5

Add the small playwright-core library for PDF export?

RecommendedYes.

AlternativesThe browser's own "Save as PDF" only.

WhyIt drives the Chrome or Edge already installed on the machine, with no browser download, and gives high-quality PDFs with real colours, links and bookmarks.

D6

Should the per-country advice get a GPT cross-family review?

RecommendedFollow the same review switch as image review, which is currently turned OFF.

AlternativesAlways on · always off.

WhyOne review switch is simpler to reason about than a second toggle, and it stays consistent with today's setting.

D7

Accept the starting values for "Suggested next research"?

RecommendedAccept: 90% or more of images reused from the US means "nothing new"; a pattern split 40–60% is weak; fewer than 4 games is thin; store data older than 30 days is stale.

AlternativesPick different starting thresholds now.

WhyThese are reasonable defaults and are stored as plain config values, so all of them are adjustable later without code changes.

D8

Which concepts should the terminology comparison track to start with?

RecommendedYour seven (battle, play, hero, upgrade, summon, free, reward) plus: gacha / draw, idle / AFK, roguelike, stage, boss, equipment, skill, event, login bonus.

AlternativesOnly your seven · edit the list (add a note).

WhyThese are the words most store pages in this genre use in headlines. The list lives in a config file, so you can change it any time.

D9

How many A/B tests per report, and how is expected impact stated?

RecommendedUp to 5 tests per report, with impact in words (small, medium, large) rather than invented percentages.

AlternativesMore or fewer tests · percentage estimates.

WhyFive is enough to act on. Percentages would look precise without real data behind them. Note: Google Play experiments measure install clicks, and run per language or custom store listing, not per country; the tool works out the setup for you.
